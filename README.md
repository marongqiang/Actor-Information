# Actor-Information

智能网盘影视库 (smart-media-vault) — 管理 115 网盘中的影视文件，自动刮削元数据（海报、演员、简介等），提供海报墙浏览、演员库管理、播放进度追踪、分组管理等功能。

## 技术栈

| 类别 | 技术 |
|------|------|
| 桌面框架 | Tauri 2.0 |
| 前端 | Vue 3 + TypeScript + Element Plus |
| 后端 | Rust 2021 |
| 数据库 | SQLite (WAL 模式) |
| 构建 | Vite 5.4 |
